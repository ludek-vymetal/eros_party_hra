# EROS – Vize projektu

## Filozofie

EROS není erotická hra.

EROS není seznam úkolů.

EROS je digitální kronika vztahu.

Scénáře nejsou cílem.

Scénáře vytvářejí společné zážitky.

Deník uchovává společné vzpomínky.

Partnerství není statické.

Lidé se mění.

Hranice se mění.

Důvěra se vyvíjí.

Proto žádný scénář nemusí být odmítnut navždy.

Každý scénář může být po letech znovu objeven.

EROS má být aplikace, kterou budou páry otevírat i za deset let.
