# ❤️ RelationshipChapter

RelationshipChapter představuje jednu kapitolu společného života dvou partnerů.

Nevzniká ručně.

Vzniká automaticky jako výsledek společné interakce.

Každá kapitola se může celý život dále rozvíjet.

---

# Struktura kapitoly

RelationshipChapter

├── Basic Information
├── Scenario
├── Participants
├── Timeline
├── Media
├── Notes
├── Permissions
