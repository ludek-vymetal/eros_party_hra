# Relationship Book

Každá kapitola představuje skutečný okamžik vztahu.

Nevzniká automaticky.

Vzniká pouze tehdy, když se oba partneři rozhodnou, že tento okamžik stojí za zapamatování.

Každá kapitola obsahuje:

- název
- datum
- scénář
- fotografie
- pocity autora
- pocity partnera
- společné poznámky
- možnost vrátit se po letech

Smyslem není archivovat scénáře.

Smyslem je uchovat emoce.
